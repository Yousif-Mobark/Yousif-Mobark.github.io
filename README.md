# Yosuf Mobark — CV

Single-page CV site. Hand-coded HTML/CSS, scroll-reveal with vanilla `IntersectionObserver`,
animated connected-node background in [p5.js](https://p5js.org).

Published via GitHub Pages at: **https://yousif-mobark.github.io/cv/**

## Files

- `index.html` — markup
- `style.css` — layout, type, animations
- `sketch.js` — p5.js background sketch (Perlin flow field + mouse attraction)
- `yosuf-mobark-cv.pdf` — downloadable CV
